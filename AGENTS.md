## Назначение
CORTEX — проект открытой AIOps-платформы проактивного управления микросервисами в Kubernetes, одновременно программная и исследовательская часть ВКР ТПУ.
Тема: «Разработка интеллектуальной платформы управления жизненным циклом микросервисной инфраструктуры на основе методов машинного обучения и больших языковых моделей».

Четыре основных направления:
1. ML-маршрутизация: скоринг здоровья подов и распределение трафика через API-шлюз.
2. Предиктивное масштабирование: прогноз нагрузки и управление числом реплик.
3. RAG-анализ логов и трейсов: поиск первопричин инцидентов с привязкой к `trace_id`.
4. DevOps LLM-агенты с инструментами диагностики и безопасного выполнения действий.

## Структура и целевой стек
- `backend/` — API-шлюз, Kafka-интеграции и демо-сервисы; Java 21 / Kotlin, Spring Boot 3.3+, Spring Cloud Gateway, Resilience4j.
- `ml/` — ML-маршрутизатор, прогнозирование, RAG и агенты; Python, библиотеки ML; Spring AI / LangChain4j, Qdrant, Ollama либо внешний LLM API (конкретные варианты ещё требуют выбора).
- `infra/` — Kubernetes (k3s), Helm, Prometheus, Grafana, OpenTelemetry, Jaeger, k6 и сценарии Chaos Engineering.
- Kafka — событийная шина; в ТЗ указаны `cortex.telemetry.metrics`, `cortex.telemetry.spans`, `cortex.alerts.system`.

## Ключевые требования из чернового ТЗ
- При недоступности ML или ответе дольше 10 мс шлюз переходит на Round-Robin / Least Connections; отказ AI не должен вызывать клиентские 5xx.
- KPI для проверки: ML-инференс ≤ 8 мс, переключение fallback ≤ 2 мс, снижение p95 latency минимум на 15% при частичной деградации пода. Это целевые показатели, не результаты измерений.
- Прогнозирование: история за 15 минут, горизонт 2–5 минут; расчёт числа реплик по прогнозируемому RPS и производительности пода.
- Политика разрабатываемых DevOps-агентов: чтение выполняется автономно; изменения требуют плана и подтверждения оператора. Удаление namespaces, баз данных и PV/PVC запрещено.
- Первое демо: сравнение ML-маршрутизации с Round-Robin при деградации одного пода, с нагрузкой k6 и измерением p95/p99.
