# CORTEX — Интеллектуальная AIOps-платформа управления микросервисной инфраструктурой

## 📌 О проекте

**CORTEX** — это открытая AIOps-платформа, внедряющая интеллектуальный контур управления в распределённую микросервисную инфраструктуру под управлением Kubernetes. Платформа переводит эксплуатацию микросервисов из реактивного режима в проактивный за счёт машинного обучения и больших языковых моделей (LLM).

### Ключевые возможности:
1. **Интеллектуальная маршрутизация (ML Routing):** адаптивное перенаправление трафика на здоровые и производительные поды на основе ML-скоринга состояния узлов (эффективнее Round-Robin).
2. **Предиктивный автоскейлинг (Predictive Autoscaling):** прогнозирование временных рядов нагрузки и упреждающее масштабирование реплик до наступления деградации (устраняет запаздывание стандартного HPA).
3. **RAG-анализ распределённой телеметрии:** семантический поиск по логам и распределённым трейсам (OpenTelemetry / Qdrant) и ускоренная локализация первопричин сбоев (Root Cause Analysis).
4. **DevOps LLM-агенты:** автоматизация рутинных операций обслуживания инфраструктуры с многоуровневыми политиками безопасности (*Guardrails*) и обязательным подтверждением мутирующих действий (*Human-in-the-Loop*).
5. **Безотказность (Graceful Fallback):** мгновенный откат шлюза на классические алгоритмы балансировки при любых сбоях или задержках в AI-компонентах.

## 🏗 Структура репозитория

```text
.
├── backend/            # Ядро платформы: API-шлюз (Spring Cloud Gateway), Kafka-пайплайны, демо-сервисы
├── ml/                 # Машинное обучение: модели маршрутизации, предиктивный скейлер, RAG и агенты
├── infra/              # Инфраструктура: манифесты Kubernetes (k3s), Helm-чарты, мониторинг, k6, chaos
└── docs/               # Академическая и проектная документация (ВКР, ТЗ, Obsidian Vault)
    ├── md/             # Главы ВКР, ТЗ и граф зависимостей задач
    └── .obsidian/      # Конфигурация базы знаний Obsidian
```

## 🛠 Технологический стек

* **Backend:** Java 21 / Kotlin, Spring Boot 3.3+, Spring Cloud Gateway, Resilience4j, Apache Kafka, Testcontainers.
* **ML / AI:** Python, scikit-learn, LangChain4j / Spring AI, Qdrant, Ollama (Llama 3 / Mistral / Qwen 2.5).
* **Инфраструктура & Observability:** Kubernetes (k3s), Helm, Prometheus, Grafana, OpenTelemetry, Jaeger.
* **Тестирование & Бенчмарки:** k6 (нагрузка), Chaos Engineering (моделирование сбоев), JUnit 5.
